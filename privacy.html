저장과 전송

브라우저가 Google의 계정 확인과 Analytics API에 직접 요청합니다. 로그인 토큰·계정 확인 응답·보고서는 브라우저 메모리에서 처리합니다. 보고서는 최대 5분간 메모리 캐시로 재사용하며 연결 해제·새로고침·페이지 종료 때 제거됩니다. OAuth 클라이언트 ID와 게임별 속성 연결 설정만 해당 브라우저의 로컬 저장소에 저장합니다. Google API 처리에는 Google의 정책이 적용되며 호스팅 제공자는 사이트 제공에 필요한 접속 정보를 처리할 수 있습니다.

선택한 서버 집계 파일

UnderSpark 전용 화면에서 사용자가 선택한 식별자 없는 집계 JSON을 브라우저 메모리에서 읽습니다. 파일을 서버로 업로드하거나 브라우저의 영구 저장소에 보관하지 않습니다. 불러온 자료 해제·게임 변경·연결 해제·페이지 종료 또는 30분 경과 시 해제합니다. 파일의 원본 정정·삭제는 자동 전파되지 않으므로 최신 자료로 다시 확인해야 합니다.

사용과 공유

Google API 보고서는 사용자가 요청한 운영 분석에 사용합니다. 판매·광고 타기팅·AI 학습에 제공하지 않습니다. Google API Services User Data Policy의 Limited Use 요건을 따릅니다.
